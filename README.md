## 使用

1. 将 APK 和自己的 WPK 模型文件复制到手机。
2. 安装并打开“WPK 模型馆”。
3. 点击“导入 WPK”，选择模型，等待入库。
4. 点击模型卡片查看；轻点原模型区域互动，单指拖动模型，双指缩放和移动。

右下角“区域”按钮显示／关闭点击范围，齿轮进入设置。设置提供视图、帧率与画质、文本显示、触发区域样式、状态保存、暂停、动作、部件、背景、运行信息与语言，以及返回模型馆。

模型保存在应用私有目录。卸载应用会移除已导入的模型和状态。
